# MARQUEE

A browser-based space shooter built with **HTML**, **CSS**, and **JavaScript**.

## Play the Game

- **Play on GitHub Pages:** https://jbb0807.github.io/JavaScript-Game-Project/

---

## Flight Manual (How to Play)

### Controls
| Action | Keys |
|---|---|
| Move | `W` `A` `S` `D` **or** Arrow Keys |
| Fire | `Spacebar` |
| Pause | `Esc` |

### Objective
Complete by reaching the end of the stage. **Light Speed!**

---

## Getting Started (In-Game)

1. Enter your **Player Name** on the main menu.
2. Choose a **Difficulty**.
3. Click **Start Game**.

### Menu / UI
- Use the header buttons for **Help**, **Pause**, and **Credits**.

---

## Tech
- Vanilla JavaScript
- HTML / CSS
